The World in One Day — a one-page newspaper front page summing up Wednesday 25 November 2026: 50 verified stories (3 heroes with full scene illustrations, 13 illustrated mid stories, 34 more in a balanced list), a giant date masthead, a number strip, a filled-land world map with numbered pins, and a DATE CHECK box listing what was deliberately left out as earlier news. Every story happened or was first reported on 25 November 2026 only.

## Run it

```sh
python3 render.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`render.py` draws `entry.png` (1024×1024, <1 MiB) with Pillow; `main.ts` copies it to the output directory.
